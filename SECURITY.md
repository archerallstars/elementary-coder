# Security

This repository is skill text (`SKILL.md`, `README.md`, `TESTING.md`, `AGENTS.md`, `LICENSE`). It is not a running service.

- It stores no credentials, API keys, AppKeys, tokens, or user data.
- Agents following this skill must never paste real secrets into comments, `TESTING.md`, `SECURITY.md`, or commit messages (rule 23).
- Install copies of `SKILL.md` into a harness skills directory are the same public text.

There is no threat model beyond treating this tree as public documentation.
